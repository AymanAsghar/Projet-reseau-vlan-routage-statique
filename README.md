# Projet-réseau-VLAN-routage-statique

## 📌 Description
Projet académique de mise en place d'une infrastructure réseau multisites segmentée avec VLANs, EtherChannel, Router-on-a-Stick et routage statique WAN.

Ce projet a été réalisé dans le cadre d'un travail pratique de conception et configuration réseau avancée, simulant un environnement d'entreprise avec plusieurs sites interconnectés.

---

## 🏗️ Architecture du projet
L'infrastructure comprend :
- **Segmentation VLAN** pour isolation logique des services
- **EtherChannel** pour agrégation de liens et redondance
- **Router-on-a-Stick** pour l'interconnexion des VLANs
- **Routage statique WAN** pour la connectivité entre sites
- **Sous-réseaux** pour différents services (administration, utilisateurs, serveurs)
